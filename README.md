# 雷霆战机 (Thunder Fighter)

一个纯 HTML + Canvas 的竖屏射击小游戏，无需任何依赖，浏览器打开即玩。

## 玩法

- **移动**：方向键 / `WASD`，或在触屏/鼠标上拖动
- **射击**：自动开火
- **暂停**：`P`
- **开始 / 重开**：`空格` / `回车` / 点击屏幕

## 内容

- 三种普通敌机（小 / 中 / 大）与周期出现的 **Boss**
- 火力升级、护盾、全屏炸弹、生命恢复四种道具
- 连击加分、关卡递进、本地最高分记录
- 合成音效（Web Audio，无需音频文件）、粒子爆炸、星空卷轴背景

## 运行

直接用浏览器打开 `index.html` 即可；也可以用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 在线游玩

打开 GitHub Pages 即可游玩（本仓库已配置为从 `main` 分支根目录发布）。
